這篇是測試夾具（tests/site.test.ts 的「草稿在全站隱藏」與「只含草稿的主題不出現」會用到），請不要刪除，也不要把 `draft` 改成 `false`。

它所在的 `draft-topic/` 主題只有這一篇草稿，用來驗證：

- 沒有已發布文章的主題不會出現在側欄和首頁。
- 非 MobX 主題的草稿同樣沒有頁面、不在搜尋索引裡，也不算進任何主題的「共 M 篇」。
- 測試工具確實掃到了 `mobx` 以外的主題資料夾。

## 草稿主題專用小節：不該被搜尋到

如果你在網站上或搜尋結果裡看到這段文字，代表只含草稿的主題沒有被正確隱藏。
